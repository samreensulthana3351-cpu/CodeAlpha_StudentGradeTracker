# CodeAlpha Student Grade Tracker

## Project Overview
A Java console application developed as part of my CodeAlpha Java Programming Internship.

## Features
- Add student names and marks
- Calculate student grades
- Display all student records
- Calculate average marks
- Find highest and lowest marks
- Validate user input
- Display class statistics

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Visual Studio Code

## How to Run
1. Install the Java JDK.
2. Open the project folder in a terminal.
3. Compile the program:
   javac StudentGradeTracker.java
4. Run the program:
   java StudentGradeTracker

## Learning Outcomes
Practised Java classes, constructors, collections, loops, methods, conditional statements, and input validation.
